# Caso sintético de desembarques

`synthetic-landings.csv` contiene 40 registros inventados para actividades sobre código, versiones y reproducibilidad. No representa observaciones, estimaciones ni sistemas institucionales.

El conjunto permite practicar lectura, validación de esquema y tipos, detección de valores inválidos, resúmenes simples y exportación reproducible. Los valores se diseñaron únicamente con fines pedagógicos; `quality_flag` incluye estados `ok`, `review` e `invalid` para ejercitar controles.

La especificación de campos está en `metadata.yml`. Los scripts de ejemplo se encuentran en `scripts/r/part-iv/`, `scripts/python/part-iv/` y `scripts/sql/part-iv/`.
